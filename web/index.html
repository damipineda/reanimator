Reanimator: Lunar Lander

A decompiled Flash/AS2 simulation (PhET's Lunar Lander), rebuilt as editable HTML5/JS, with a measured (not claimed) equivalence check against the original. Everything on this page is read from already-generated, cached files - no API key, no live LLM call, no network request other than this page's own same-origin files.

https://phet.colorado.edu

This work has been modified from the original: it is an independent HTML5/JS reconstruction derived by decompiling and analyzing the original Flash (.swf) file, not the original simulation itself.

The original .swf file is NOT distributed with this project and is not used by anything on this page - the game below is a standalone rebuild. See samples/SOURCES.md for this sample's full provenance/license record and why the original file stays local-only, never committed.
